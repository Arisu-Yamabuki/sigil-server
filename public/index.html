Sigil

Only you and the person you talk to can read it.

Sigil encrypts every message on your phone before it leaves. This server only relays and stores scrambled text it cannot read.

How it works

  1. Create an account

    Pick a username and password. The password proves who you are to the server. It does not unlock your keys.

  2. Set up your keys on your phone

    Create a new GPG key or import one. Your private key stays on your device and is never uploaded.

  3. Your public key is shared

    Only your public key goes to the server. Anyone who searches your username gets that public key.

  4. Encrypt before sending

    Your phone encrypts each message with the recipient's public key. The server only receives ciphertext.

  5. Decrypt on arrival

    The recipient's phone decrypts the message with its private key and shows it. Nothing is readable in transit or on the server.

Message path

Alice's phone plaintext ──encrypt with Bob's PUBLIC key──▶ ciphertext │ ▼ Sigil server (stores ciphertext + timer metadata only) │ ▼ Bob's phone ciphertext ──decrypt with Bob's PRIVATE key──▶ plaintext

Timers

A chat timer applies only to messages sent after it was set. Older messages keep their original rules. A per-message timer overrides the chat timer for that one message. Expired messages are removed from the database automatically.

API

MethodEndpointPurpose
POST/api/auth/registerCreate an account
POST/api/auth/loginLog in, returns a token
GET/api/users/search?q=Find users by username prefix
GET/api/users/:username/public-keyFetch a public key only
PUT/api/users/me/public-keyUpload your public key
GET/api/messages/with/:usernameGet ciphertext for a chat
POST/api/messagesSend ciphertext
DEL/api/messages/:idDelete a message you sent
PUT/api/messages/conversation/:username/timerSet the chat timer

What the server can and cannot see

Can seeUsernames, password hashes, public keys, ciphertext, timestamps, timer settings
Cannot seeMessage contents, private keys, your key passphrase
Never storedProfile pictures, avatars, device identifiers
