Privacy Policy

Effective date: November 4, 2026

Sigil (“we”, “our”, “us”) runs the Sigil Android app and the relay server at https://sigil.adnand.com. Sigil is open source and built so that we cannot read your messages or access your private keys.

1. What the server stores

  • Account data: your username and a bcrypt hash of your password. We never see or store your plaintext password.
  • Public keys: your public GPG key, so others can encrypt messages to you. Anyone can look it up by username.
  • Ciphertext: encrypted messages. The server cannot read them.
  • Metadata: timestamps, sender and recipient usernames, and your timer settings. We use these to delete expired messages.

2. What the server never receives

  • Message contents, private keys, or key passphrases.
  • Profile pictures, avatars, or device identifiers. Sigil has no such feature.

3. What stays on your phone

  • Your private key is stored in app-private storage, protected by your key passphrase. It is never uploaded.
  • Signing out keeps this encrypted key on the phone. “Delete keys” in the Keys screen erases it.
  • Decrypted messages are kept only in memory and are cleared when you leave a chat.
  • Android cloud backups are disabled, so keys and messages are not copied off the device.

4. Retention and deletion

  • Messages with a timer are deleted from the server automatically when the timer expires.
  • You can edit or unsend messages you sent. Unsending removes the ciphertext from the server.
  • To delete your account and all server data, contact us using the details below.

5. Sharing

We do not sell, rent, or share user data with third parties, advertisers, or analytics providers. The server holds no readable message content to share.

6. Security notes

  • Screens use FLAG_SECURE, which blocks screenshots and recent-apps previews.
  • The server sees metadata: who messages whom, and when. End-to-end encryption protects content, not metadata.
  • If you lose your private key and have no backup, past messages cannot be recovered.

7. Changes

We may update this policy as the app changes. The current version is published at this page and in the open-source repository on GitHub.
